# NC CEO闭门交流会 - 互动网页

## 项目结构

```
nc-event/
├── opening/           # 开场视觉页
│   ├── index.html
│   ├── style.css
│   └── script.js
└── canvas/            # 五维画布共创互动
    ├── index.html     # 大屏展示页
    ├── submit.html    # 手机提交页
    ├── style.css
    ├── script.js
    └── submit.js
```

## 使用方法

### 1. 开场视觉页

**直接在浏览器打开：** `opening/index.html`

**操作：**
- 点击"下一页"或按 `→` 键（空格也可）切换场景
- 点击"上一页"或按 `←` 键返回
- 共5个场景：标题 → 数字真相 → 金句 → 物种标签 → 参会企业

---

### 2. 五维画布共创

#### 大屏展示页
**直接在浏览器打开：** `canvas/index.html`

**功能：**
- 实时显示各组的提交内容
- 可按小组筛选（全部/第一组/第二组/线上组）
- 底部显示提交统计

#### 手机提交页
**在同一电脑打开：** `canvas/submit.html`

**流程：**
1. 选择小组
2. 选择企业
3. 逐层填写（共5层）
4. 提交

---

## ⚠️ 重要说明：数据同步限制

**当前方案：** 使用 `localStorage` + `BroadcastChannel`

**限制：** 
- ✅ 同一台电脑的不同标签页可以实时同步
- ❌ **不同设备无法同步**（手机扫码提交后，大屏不会实时更新）

### 解决方案（推荐）

**方案A：现场操作**
1. 大屏展示页在主电脑打开
2. 手机提交页在**同一台电脑**的另一标签页打开
3. 现场用这台电脑演示或由工作人员代填

**方案B：部署到公网（需要额外配置）**
如果需要真正的跨设备同步，我可以帮你：
1. 部署到 Vercel（免费）
2. 接入 Firebase Realtime Database 或 Supabase（免费额度足够）
3. 实现真正的跨设备实时同步
